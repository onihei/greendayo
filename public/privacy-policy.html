1. 取得する情報

  • ログイン時に連携サービスから受け取る情報: GitHub または X（旧 Twitter）のアカウント識別子、表示名、プロフィール画像の URL、メールアドレス（連携サービスで登録・公開されている場合）
  • 利用者が入力・投稿する情報: 掲示板の投稿、メッセンジャーのメッセージ、プロフィールの回答内容、アップロードした画像
  • ブラウザに保存する情報: ニックネーム、ゲームの設定や識別子などを、利用者の端末のローカルストレージに保存します。これらは利用者の端末内に保存され、ゲームのオンライン対戦などに必要な範囲でサーバに送信されます。
  • アクセスログ: IP アドレス、アクセス日時、閲覧した URL、ブラウザの種類（ユーザーエージェント）。サーバが自動的に記録します。

本サービスは、広告配信やアクセス解析のための Cookie・トラッキングツールを使用していません。

2. 利用目的

  • ログイン状態の管理と本人の識別
  • 掲示板、メッセンジャー、プロフィール、ゲーム等の機能の提供
  • 同じ方が複数のアカウントを作成してしまうことを防ぐための照合（メールアドレス）
  • 不正利用の防止、障害対応、規約違反への対応
  • お問い合わせへの対応

取得した情報を、上記以外の目的に利用することはありません。

3. 公開される情報

表示名、プロフィール画像、プロフィールの内容、掲示板の投稿は、本サービス上で他の利用者や未ログインの閲覧者に公開されます。メールアドレスは公開されません。メッセンジャーのメッセージは、会話の参加者に表示されます。

4. 外部サービスの利用

本サービスは、次の外部サービスを利用しており、必要な範囲で情報がこれらのサービスに送信・保存されます。

  • Google Firebase（Firebase Authentication、Cloud Firestore）: ログイン情報、投稿、メッセージ、プロフィールの保存。Firebase のプライバシーとセキュリティ
  • GitHub / X: ログインのための認証
  • Anthropic（Claude）: プロフィールの自己紹介文生成機能を使った場合に限り、入力した回答内容を送信して文章を生成します。Anthropic のプライバシーポリシー
  • さくらインターネット（さくらの VPS）: ウェブサーバ、アップロード画像、アクセスログの保存（日本国内）

Firebase および Anthropic のサーバは日本国外に所在する場合があります。

5. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。

6. 管理

運営者は、取得した情報の漏えい、滅失、毀損を防ぐため、アクセス制限など合理的な安全対策を講じます。運営者は、障害対応や規約違反への対応に必要な場合に限り、保存されたデータを確認することがあります。

利用者は、自身の情報の開示、訂正、削除、利用停止を求めることができます。アカウントや投稿データの削除を希望する場合は、下記のお問い合わせ先までご連絡ください。ご本人であることを確認したうえで対応します。
